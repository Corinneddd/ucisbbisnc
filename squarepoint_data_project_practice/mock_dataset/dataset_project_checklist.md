## 5. EDA：Solar 日发电量与分布

- [ ] 【截图版本】从小时 Solar 降采样至日。

- [ ] 【已讨论补充】检查每日覆盖率，避免缺几个小时的总量被误认为正常低发电日。

### 5.2 趋势、季节性和分布

- [ ] 【截图版本】画日发电量序列，分析长期趋势与年度季节性。
- [ ] 【已讨论补充】画按月箱线图、histogram 和 Q–Q plot。
- [ ] 【截图版本】判断原始日发电量是否接近正态，并给出图形证据。
- [ ] 【共同要求】完成去季节性，根据数据决定是否同时去趋势。
- [ ] 【已讨论补充】可以比较平滑趋势与年度周期项；例如 g(Y_d) = T(d) + S(day_of_year) + residual。
- [ ] 【已讨论补充】区分年份间水平变化与年度周期，不把所有变化都归因于季节。

### 5.3 分布变换与解释

- [ ] 【截图版本】尝试使分布更接近正态。
- [ ] 【已讨论补充】比较适用的 log、Box–Cox、Yeo–Johnson；Box–Cox 要求严格正值。
- [ ] 【已讨论补充】比较变换、去趋势、去季节性前后分布，以及剩余部分的方差变化。
- [ ] 【已讨论补充】讨论先变换再去季节性是否更合适，不假设某一个固定处理顺序必然最佳。
- [ ] 【已讨论补充】用于预测时，变换和季节性估计参数只在训练部分拟合，避免未来信息泄漏。
- [ ] 【延伸】可补充偏度、峰度和正态性检验；说明大样本和时间依赖对 p-value 解读的影响。

**必须能解释**

- z-score 标准化不等于正态化。
- 去季节性不保证残差正态。
- 小时 Solar 的夜间零值特征不能直接套到日总量。
- OLS 不要求原始 X 或 Y 正态；经典正态误差假设主要影响相应的统计推断。
- 更像正态不自动代表预测更准确。

**产出：** 日 Solar 数据、趋势与季节性图、变换前后分布对比及方法解释。

- [ ] 【文字版本】利用已验证的 y = a x + b，在另一变量可见时直接恢复目标。

- [ ] 【已讨论补充】关系参数与选择不应利用验证中本应隐藏的真值。

- [ ] 【已讨论补充】以实际验证误差决定采用与否，不把 0.99 当普适规则。
- [ ] 【已讨论补充】检查连续缺失、快速爬坡、突变和长常数区间的影响。
- [ ] 【已讨论补充】区分真实上一小时值与递归前向填充值；后者可能已经偏离很久以前的真实观测。

- [ ] 【文字版本】特征组 A：目标自身 lag information + 时间信息（hour、month 等）。
- [ ] 【文字版本】特征组 B：A + 与目标相关的其他数值变量。

- [ ] 【已讨论补充】Ridge 前做训练集拟合的特征标准化，在 validation 上选 alpha。
- [ ] 【文字版本】逐变量选择；模型有稳定提升才采用，否则保留简单 baseline。
- [ ] 【已讨论补充】不同变量可以采用不同方法，避免强求统一。

## 8. Part 2B：Thermal 预测

### 8.1 合法特征

- [ ] 【截图版本】确认 Thermal 目标及其定义。
- [ ] 【截图版本】使用 Wind、Solar 截至 t 的信息。
- [ ] 【截图版本】其他发电类别仅使用 t−1。
- [ ] 【已讨论补充】确认是否允许 Thermal 自身历史；未确认不直接加入。
- [ ] 【已讨论补充】在完整时间索引上构造特征，核对 X_t 与 y_t 的对齐。
- [ ] 【已讨论补充】检查总量／衍生量是否包含目标，避免间接读取 Thermal。
- [ ] 【已讨论补充】基础特征组：当期 Wind、Solar + 日历信息。
- [ ] 【已讨论补充】扩展特征组：基础组 + 其他类别 lag 1。

### 8.2 模型与验证

- [ ] 【已讨论补充】建立符合信息限制的简单 baseline；Thermal persistence 仅在允许其历史时使用。
- [ ] 【已讨论补充】比较 OLS 与标准化后的 Ridge。
- [ ] 【已讨论补充】按时间顺序切分，必要时做多个向前滚动验证窗口。
- [ ] 【已讨论补充】预处理、特征选择、季节性估计和调参限定在训练／验证范围；test 不参与选择。
- [ ] 【已讨论补充】各模型在相同可评分时间点上比较。
- [ ] 【已讨论补充】报告 MAE / RMSE，按月份、小时、发电水平检查误差。
- [ ] 【已讨论补充】validation 选方法，test 做最终评估。
- [ ] 【已讨论补充】不默认用 MAPE；目标接近零时其表现可能不稳定。
- [ ] 【已讨论补充】先完成线性模型和 baseline，时间充裕再比较非线性模型。
- [ ] 【延伸】检查残差时间结构、持续偏高／偏低和失效区间。

**产出：** 特征可用性表、模型比较、最终测试结果、实际值与预测值对比图。

## 9. 特征选择与面试追问

### 9.1 “Explanatory variables / features 是怎么选的？”

- [ ] 【文字版本】掌握 full model → permutation importance → 删除低贡献特征 → 重训比较的思路。
- [ ] 【已讨论补充】先按题目信息集和预测时可用性筛选，再结合时间结构／变量含义，最后用验证表现决定。
- [ ] 【已讨论补充】做特征组消融：增加／删除一组特征是否带来稳定增量改善。
- [ ] 【已讨论补充】解释相关特征可互相替代，单变量 importance 低不代表该组信息无用。
- [ ] 【已讨论补充】解释任意打乱时间序列可能产生不自然的组合，importance 只能辅助判断。
- [ ] 【文字版本】建模时考虑从确定性共线变量中保留一个，并解释理由。
- [ ] 【延伸】不能把重要性或回归系数直接解读为因果效应。

参考回答逻辑：合法且可用的信息 → 有意义的候选特征组 → 时间验证 → 消融检查；permutation importance 作为辅助诊断。

### 9.2 “为什么 Ridge 和 OLS 几乎一样？”

- [ ] 【文字版本】准备解释共线性较弱这一可能原因，但不将其当唯一结论。
- [ ] 【已讨论补充】检查样本多、特征少，是否使 OLS 的估计方差已经较低。
- [ ] 【已讨论补充】检查选出的 alpha 是否很小，导致 Ridge 接近 OLS。
- [ ] 【已讨论补充】检查是否标准化，以及 alpha 搜索范围是否合适。
- [ ] 【已讨论补充】检查两个模型是否受相同的线性假设限制，如遗漏非线性或交互。
- [ ] 【已讨论补充】比较系数和预测：系数可能不同，预测仍相近。
- [ ] 【已讨论补充】解释 Ridge 的偏差—方差权衡；它不仅用于处理共线性。
- [ ] 【已讨论补充】明确“预测接近”不能反推出“没有共线性”。

### 9.3 其他需能解释的关键问题

- [ ] 【已讨论补充】为什么不用随机切分作为唯一验证？
- [ ] 【已讨论补充】为什么当期其他变量在某个版本合法，在另一个版本受限？
- [ ] 【已讨论补充】真实缺失没有标签，如何评估 imputation？
- [ ] 【已讨论补充】为什么 lag-1 correlation 高仍可能填不好长缺口？
- [ ] 【已讨论补充】为什么不直接删除所有缺失行或只训练全表完整行？
- [ ] 【已讨论补充】为什么 Solar 不需要强行变成正态才能做回归？
- [ ] 【已讨论补充】如何区分真实零值、缺失和数据口径变化？
